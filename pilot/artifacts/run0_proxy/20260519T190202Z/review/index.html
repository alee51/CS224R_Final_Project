What is Run 0? i

Run 0 (run0_proxy) was a no-training proxy rollout pass: the frozen base model (Qwen/Qwen3-1.7B-Base) sampled 8 completions per prompt on rows 0–499 of dapo_slice_3k.jsonl (same train pool as the later GRPO runs).

Purpose: validate whether cheap exact-match answer clustering (not an LM judge) produces diverse enough rollouts for minority-based RL—before spending on training runs.

This dashboard shows:

  • Each problem, gold answer, and all 8 raw model completions
  • Stored parsed_answer, correct, and cluster_id from the Run 0 artifact pipeline
  • Filters to browse prompts by how many rollouts were marked correct

For completion-based re-analysis, see analysis_v2_quant.md and analysis_v2_qual.md in the parent artifact folder.
